Política de Privacidade

Última atualização: 3 de outubro de 2026.

O GranaLeve é uma ferramenta de organização financeira pessoal. Ele não solicita senha bancária, número de cartão ou acesso direto à sua conta bancária.

1. Quais dados são tratados

O GranaLeve pode tratar o e-mail usado no cadastro ou login, identificadores técnicos de autenticação e os dados financeiros que você próprio registra, como descrições, valores, categorias, datas e contas a vencer. No login com Google, o serviço de autenticação pode receber os dados básicos necessários para identificar sua conta.

2. Para que os dados são usados

Os dados são usados para autenticar sua conta, sincronizar seus lançamentos entre dispositivos, exibir resumos financeiros, permitir backup e restauração e manter o funcionamento e a segurança do serviço.

3. Onde os dados ficam

O GranaLeve usa serviços de infraestrutura em nuvem para autenticação, banco de dados e hospedagem. Esses fornecedores podem processar dados técnicos necessários para prestar o serviço. O GranaLeve não vende os seus dados pessoais.

4. Segurança e acesso

Os registros são separados por usuário por meio de regras de acesso no banco de dados. A aplicação usa uma chave pública apropriada para o navegador; credenciais administrativas não ficam expostas no código do site.

5. Backup e armazenamento local

Se você baixar um backup, o arquivo passa a ficar sob sua responsabilidade no dispositivo onde foi salvo. O navegador também pode manter dados técnicos de sessão e, em versões anteriores, dados locais usados na migração para a nuvem.

6. Exclusão da conta

Dentro do próprio GranaLeve, na área “Conta e privacidade”, você pode solicitar a exclusão permanente da sua conta. A exclusão remove a conta de autenticação e os registros financeiros associados no banco de dados. Backups que você baixou para seu próprio dispositivo não podem ser apagados pelo GranaLeve.

7. Seus direitos

Você pode acessar, corrigir, exportar e excluir os dados que mantém no GranaLeve usando os recursos disponíveis no próprio aplicativo. Para questões adicionais de privacidade, utilize o canal oficial de suporte pelo qual o GranaLeve foi disponibilizado a você.

8. Alterações nesta política

Esta política pode ser atualizada quando houver mudanças relevantes no funcionamento do serviço. A data da versão mais recente será informada no topo desta página.
